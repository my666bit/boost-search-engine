Function template set

boost::container::set

Synopsis

// In header: <boost/container/set.hpp>


template<typename InputIterator> 
   set(ordered_unique_range_t, InputIterator, InputIterator);

Description

Deduction guide: allows a set to be constructed from an already ordered, unique iterator range [first, last), deducing the key type from InputIterator and using the default comparator and allocator.
