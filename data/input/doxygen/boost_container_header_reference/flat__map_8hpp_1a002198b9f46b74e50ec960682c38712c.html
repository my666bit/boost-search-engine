Function template flat_map

boost::container::flat_map

Synopsis

// In header: <boost/container/flat_map.hpp>


template<typename InputIterator, typename AllocatorOrCompare> 
   flat_map(InputIterator, InputIterator, AllocatorOrCompare const &);

Description

Deduction guide: allows a flat_map to be constructed from the iterator range [first, last), deducing the key and mapped types from InputIterator. The trailing argument is used as the allocator if it is an allocator type, otherwise it is used as the comparator.
